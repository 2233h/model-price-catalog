## 这是什么

一份**价格目录**，不是对账表、不是比价器。目标是把各家模型的官方定价**按它自己的计费方式**如实呈现——
有的按 token、有的按张、有的按秒、有的分时段，不做强行归一。

## 怎么看

打开 **[在线站点](https://2233h.github.io/model-price-catalog/)**，或直接用仓库里的文件：

| 文件 | 用途 |
|---|---|
| `目录.html` | **主页面**。品牌导航、模型搜索、点击行展开明细（档位 / 六地域对比） |
| `退役日历.html` | 已下线与待下线模型、推荐替换，以及早期上架模型归档 |
| `目录草案.md` | 纯文本版目录，便于复制或 diff |
| `模型价格目录大全.xlsx` | 表格版（总览 + 25 个板块 Sheet），便于筛选计算 |

页面上几个标记的意思：

- **`🔄月-日 时:分`** —— 这行价格的**拉取时间**（各渠道各自记录，每次刷新覆盖）。蓝字可点击 = 该模型有详情页，点击能定向重新询价；灰字不可点 = 取自云厂商报价接口。
- **`🔻低价 N 区 -x%`** —— 该模型在 N 个地域同价最低，比基准地域便宜 x%。只有一个低价区时直接写区名。
- **`×1.25` / `×0.1`** —— 相对输入价的倍率，例如缓存写 = 输入 × 1.25。
- **`×2档`** —— 该计费项有两个档位（如按上下文长度分档），点击行展开看两档。
- **`〔regional〕`** —— 仅有区域端点的老款，网页默认隐藏，勾选「含老款」展开。

## 数据从哪来

**全部取自厂商官方渠道**，不采信第三方聚合站：

| 数据源 | 说明 |
|---|---|
| 阿里云百炼 国际站 API | 主源，含全部收费项 / 峰谷价 / 上下文分档（日更） |
| AWS Bedrock 报价 API | Claude 全系（周更） |
| Azure 零售价 API | GPT / OpenAI（日更） |
| Google Cloud 价目页 | Gemini（日更） |
| BytePlus 官网价目页 | Seed / 豆包 / Seedance（日更） |
| 模型详情页缓存池 | 六地域逐区实价（轮刷） |

**币种口径**：主口径为 **USD / 百万 token**（按张、按秒、按次单标）。
国内站人民币价以「〔国内站¥…〕」形式行内备注，**不做汇率折算入库**，避免历史数据被汇率污染。

**价格来源可追溯**：每行悬停能看到是哪个渠道、什么时候拉的。若某源超过 72 小时未更新，页面头部会打 ⚠️。

## 已知边界（诚实声明）

- **不保证实时**：日更链每个工作日 10:20 跑一次，价格以页面标注的拉取时间为准。
- **归档 ≠ 下线**：「退役日历」页下半部的「早期上架模型」**仍在正常售卖**，只是不属于当年款。真正的下架模型在上半部。
- **长/短文档位**：目前只有 `claude-haiku-5.5` 一款有长上下文分档（`≤200K` / `>200K`），其余 13 个 Claude 模型官方未提供第二档。
- **无发布日的模型**：早期曾有一批跨云模型拿不到官方发布日，现已通过人工查证存档 + 模型 ID 时间后缀规则补齐，**当前无一行缺发布日**。

## 更新频率

每个工作日 **10:20** 自动刷新数据源并重建全部产物；发布到本站为**手动触发**（确认无误后统一上传）。
