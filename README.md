# 模型价格目录大全 · Model Price Catalog

把各大模型厂商的**官方价目**，按各自收费框架收录成一份可检索的目录。**零依赖单文件**，浏览器直接打开即可用；GitHub Pages 托管后手机/任意网络都能访问。

## ✨ 功能
- 📊 **价格目录**（131 在售模型 · 23 个板块）：主栏仅展示当年上架，点击行展开抽屉（档位 × 收费项 / 地域价目）
- 🔍 **模型搜索** · 低价地域徽标 · 分档计价的峰谷与阶梯
- 🗓 **退役日历**：官方下线公告批次（已下线 68 / 待下线 155）· 📦 早期上架归档（75 款仍在售，仅按口径移出主栏）
- 🎨 **全收费面覆盖**：文本 · 全模态 Omni · 实时翻译 · 向量与排序 · 世界模型 · 图像生成/编辑 · 视频生成 · 语音识别/合成/实时对话/音色定制
- 🏢 **多源实测对齐**：百炼国际站官方 API · BytePlus ModelArk · AWS Bedrock · Azure · GCP Vertex
- 📄 **目录草案（Markdown）**：给人看的目录原文，分品牌按模板渲染
- 📥 **Excel 全量导出**：总览 + 各板块分表

## 📐 计价口径
- 主口径 **USD / 百万 token**；图像 `$/张`、视频 `$/秒`、语音按 token/时长/字 单标
- 全源实测，无 CNY 混杂；另附〔国内站 ¥…〕人民币原价对照，**不折入原子**
- 排序：品牌内最新优先；列取该品牌**最全收费框架**并集，缺项以 `—` 填充
- 同价的快照版与标准版并为一行（`名 / -后缀`），不同价则分列
- Batch、免费额度已按用户意见从目录整体移除（2026-09-16）
